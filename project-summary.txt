----------------------------------------------------------------------
3. HOW TO TEST THE FLOW
----------------------------------------------------------------------
1. Open Swagger UI at http://localhost:3000/api-docs (or live Render URL /api-docs).
2. Execute `POST /api/users/logon` with valid user credentials.
3. Copy the `csrf-token` from the login response body.
4. Click the green "Authorize 🔓" button at the top right of Swagger UI, paste the token into the `X-CSRF-Token` field, and click Authorize.
5. ex:Expand `POST /api/tasks/bulk`, click "Try it out", paste the bulk tasks JSON array, and click Execute.
    
    ---Bulk Task Creation ---
        • Path: /api/tasks/bulk
        • Method: POST
        • Authentication: Requires active session cookie (via /api/users/logon)
        • Headers Required:
            - Content-Type: application/json
            - x-csrf-token: <CSRF token string returned from logon endpoint>
        • Query Parameters: None
        • Request Body (JSON):
            {
            "tasks": [
                { "title": "Buy groceries" },
                { "title": "Complete Assignment 11 Presentation" }
            ]
            }
        • Expected Success Response (201 Created):
            Returns an array of newly created task objects associated with the logged-in user.

Analytics & Search REST API Endpoints

--- 1. Get User Analytics ---
• Path: /api/analytics/users/:id
• Method: GET
• Authentication: None
• Path Parameters:
    - id (integer, required): The ID of the user (e.g., 1)
• Query Parameters: None
• Request Body: None
• Expected Success Response (200 OK):
    {
      "taskStats": [
        { "isCompleted": false, "_count": { "id": 5 } },
        { "isCompleted": true, "_count": { "id": 10 } }
      ],
      "recentTasks": [
        {
          "id": 12,
          "title": "Complete Assignment",
          "isCompleted": false,
          "priority": "high",
          "createdAt": "2026-09-10T12:00:00.000Z",
          "userId": 1,
          "User": { "name": "Jim" }
        }
      ],
      "weeklyProgress": [
        { "createdAt": "2026-09-08T00:00:00.000Z", "_count": { "id": 2 } }

    }

--- 2. Get Users with Task Statistics ---
• Path: /api/analytics/users
• Method: GET
• Authentication: None
• Query Parameters:
    - page (integer, optional): Page number for pagination (default: 1)
    - limit (integer, optional): Items per page (default: 10)
• Request Body: None
• Expected Success Response (200 OK):
    {
      "users": [
        {
          "id": 1,
          "name": "Jim",
          "email": "jim@example.com",
          "createdAt": "2026-09-01T10:00:00.000Z",
          "_count": { "Task": 15 },
          "Task": [{ "id": 10 }, { "id": 11 }]
        }
      ],
      "pagination": {
        "page": 1,
        "limit": 10,
        "total": 1,
        "pages": 1,
        "hasNext": false,
        "hasPrev": false
      }
    }

--- 3. Search Tasks ---
• Path: /api/analytics/tasks/search
• Method: GET
• Authentication: None
• Query Parameters:
    - q (string, required): Search query term (minimum 2 characters)
    - limit (integer, optional): Maximum number of results to return (default: 20)
• Request Body: None
• Expected Success Response (200 OK):
    {
      "results": [
        {
          "id": 5,
          "title": "Buy groceries",
          "isCompleted": false,
          "priority": "medium",
          "createdAt": "2026-09-09T08:30:00.000Z",
          "userId": 1,
          "userName": "Jim"
        }
      ],
      "query": "groceries",
      "count": 1
    }
